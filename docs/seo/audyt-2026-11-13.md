# Audyt SEO — stable-booksy.tolpa-lukasz97.workers.dev

Data: 2026-11-13. Badana produkcja (stara nazwa „Stable Booksy”; nazwa getona.horse i nowe logo czekają w PR #61, domena jeszcze nie działa).
Rodzaj biznesu: polska aplikacja SaaS do zapisów na jazdy konne — dwie grupy odbiorców (jeźdźcy i ośrodki jeździeckie), bez lokalizacji fizycznej.
Publiczne strony: `/`, `/auth/signin`, `/auth/signup`; reszta (`/jezdziec/*`, `/osrodek/*`) za logowaniem (302 do `/auth/signin`).

## Pięć najważniejszych problemów

1. **Mapa strony wystawia strony aplikacji.** `/sitemap-index.xml` → `/sitemap-0.xml` ma 13 adresów, w tym 9 stron `/jezdziec/*` i `/osrodek/*` oraz `/auth/confirm-email/` (sprawdzone). robots.txt nie ma linii `Sitemap:`, więc i tak nikt jej nie znajduje.
2. **robots.txt bez reguł.** Tylko komentarze Cloudflare o content signals; brak `User-agent`, `Disallow` dla stron aplikacji i `Sitemap`.
3. **Brak metadanych.** Żadna strona nie ma meta description, canonical, Open Graph ani JSON-LD. Tytuły: „Stable Booksy”, „Logowanie”, „Rejestracja”.
4. **Brak stron zaufania.** Brak polityki prywatności, regulaminu, kontaktu i informacji, kto prowadzi serwis — a rejestracja zbiera imię, e-mail i hasło (RODO).
5. **Strona główna nie trafia w zapytania.** Ok. 210 słów, hasła zamiast nazw („Jeżdżę konno.”), ani razu „zapisy na jazdy konne” czy „system rezerwacji”. Dla zapytań ośrodków Google pokazuje dedykowane strony oprogramowania (np. Anolla: ~3500 słów, cennik, FAQ, opinie).

## Pięć szybkich poprawek

1. Filtr w `@astrojs/sitemap` (tylko `/`) i własny `public/robots.txt` z `Disallow: /jezdziec/`, `/osrodek/`, `/api/` i `Sitemap:`.
2. Tytuł i meta description strony głównej z frazą, np. „getona.horse – zapisy na jazdy konne i grafik stajni”.
3. `noindex,follow` na `/auth/signin` i `/auth/signup`.
4. JSON-LD Organization + WebSite + WebApplication na stronie głównej .
5. Nagłówki cache `immutable` dla `/_astro/*` i długi cache dla `/jeden-dzien/*.webp` (dziś `max-age=0`).

## Technical SEO (52)

Działa: HTTPS, HTTP/3, `lang="pl"`, treść renderowana na serwerze (bez zależności od JS), prawdziwe 404, 302 ze stron aplikacji, Googlebot dostaje to samo.

- High: robots.txt bez reguł; mapa strony z prywatnymi adresami; brak canonical/OG; strony logowania bez noindex.
- Medium: brak nagłówków bezpieczeństwa (HSTS, X-Content-Type-Options, Referrer-Policy, Permissions-Policy, frame-ancestors/CSP); `http://` nie przekierowuje na `https://`; `/favicon.ico` 404.
- Low: viewport bez `initial-scale=1`; Google Fonts z zewnętrznego hosta.

## Content Quality (38)

Działa: krótkie, naturalne zdania po polsku; wyraźny podział na dwie grupy; konkretne reguły domenowe; oś „Jeden dzień” z prawdziwymi zrzutami i dobrymi opisami alt — najsilniejszy sygnał doświadczenia.

- Critical: brak polityki prywatności, regulaminu, kontaktu, operatora.
- High: brak opisów i słów kluczowych w tytułach; cienka strona główna; brak fraz, które ludzie wpisują.
- Medium: brak zdania definiującego produkt (cytowalność); stara nazwa w tytule, pasku, nagłówku i alt (rozwiązuje PR #61).
- Low: nagłówki H3 osi czasu nieczytelne bez kontekstu („Jazda.”).

## On-Page SEO (35)

## Załącznik: gotowy JSON-LD strony głównej (po przeprowadzce na getona.horse)

Wstawić w `<head>` strony głównej jako `<script type="application/ld+json">`. `offers` z ceną 0 dodać tylko, jeśli darmowość jest potwierdzona; bez ocen i opinii, dopóki nie ma prawdziwych.

```json
{
  "@context": "https://schema.org",
  "@graph": [
    {
      "@type": "Organization",
      "@id": "https://getona.horse/#organization",
      "name": "getona.horse",
      "url": "https://getona.horse/",
      "logo": "https://getona.horse/icon-512.png"
    },
    {
      "@type": "WebSite",
      "@id": "https://getona.horse/#website",
      "url": "https://getona.horse/",
      "name": "getona.horse",
      "inLanguage": "pl-PL",
      "publisher": { "@id": "https://getona.horse/#organization" }
    },
    {
      "@type": "WebApplication",
      "@id": "https://getona.horse/#app",
      "name": "getona.horse",
      "url": "https://getona.horse/",
      "description": "Aplikacja do rezerwacji jazd konnych: jeźdźcy zapisują się na wolne godziny u instruktorów, ośrodki układają grafik, limity miejsc i przydział koni.",
      "applicationCategory": "BusinessApplication",
      "operatingSystem": "Web",
      "browserRequirements": "Requires JavaScript",
      "inLanguage": "pl-PL",
      "publisher": { "@id": "https://getona.horse/#organization" }
    }
  ]
}
```
